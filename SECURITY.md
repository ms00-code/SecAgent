# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |

## Reporting a Vulnerability

If you discover a security vulnerability in SecAgent itself, please report it
responsibly via a [GitHub Security Advisory](https://github.com/ms00-code/secagent/security/advisories/new)
rather than opening a public issue.

## Authorized Use Only

SecAgent is designed for **authorized security testing only**. Users are responsible
for obtaining explicit written permission before scanning any system they do not own.

Unauthorized use of this tool against systems you do not have permission to test
may violate computer crime laws in your jurisdiction.

The authors accept no liability for misuse.
